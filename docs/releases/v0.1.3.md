# QuotaMate v0.1.3

Windows、macOS 和 Ubuntu 统一发布为 0.1.3，使用同一 `v0.1.3` 标签的源码构建。本次新增 Ubuntu x86_64 支持，适用于 Ubuntu 22.04 / 24.04 LTS；Windows 与 macOS 保留原有功能和平台显示方式。

- 默认在右上角 AppIndicator 旁显示实时 Codex 额度，支持 5 小时、一周和账号实际返回的其他窗口。
- 点击图标打开原生菜单，可查看额度、打开主界面、刷新、管理计划任务、切换宠物和显示模式、设置开机启动或退出。
- 适配从应用菜单启动时的 Codex 查找，包括 nvm、npm 用户安装路径和 Codex 桌面应用附带的 CLI；同时修复 npm 启动器找不到 Node 的问题。
- 清理传给外部 Codex 子进程的 AppImage 打包环境，避免捆绑库和 Python 路径影响本机启动器。
- 提供 Windows 安装程序与免安装 EXE、Apple Silicon macOS DMG、Ubuntu Debian 安装包和 AppImage，以及统一的 SHA-256 校验文件。
- 增加 Linux 单元测试、原生 D-Bus 托盘与计划任务冒烟测试，以及 Ubuntu 22.04 构建、24.04 安装验证和自动发布流程。测试使用模拟 Codex，不消耗账号额度。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `QuotaMate_0.1.3_x64-setup.exe` / `QuotaMate_0.1.3_x64-portable.exe` |
| macOS Apple Silicon | `QuotaMate_0.1.3_aarch64.dmg` |
| Ubuntu 22.04 / 24.04 LTS x64 | `QuotaMate_0.1.3_amd64.deb` / `QuotaMate_0.1.3_amd64.AppImage` |

Windows 可运行安装程序或免安装版。macOS 打开 DMG，将 QuotaMate 拖入“应用程序”；完整 App 和 DMG 内的签名均经过验证，首次启动说明见附件 `macos-first-run.txt`。macOS 使用免费临时签名，尚未进行 Apple 公证；Windows 尚未使用受信任的代码签名证书。

推荐下载 `.deb` 后运行：

```bash
sudo apt install ./QuotaMate_0.1.3_amd64.deb
```

随后在应用菜单搜索 **QuotaMate**。运行前请确保本机 Codex 已安装并登录。

AppImage 可免安装运行：

```bash
chmod +x QuotaMate_0.1.3_amd64.AppImage
./QuotaMate_0.1.3_amd64.AppImage
```

缺少 FUSE 时可添加 `--appimage-extract-and-run`。SHA-256 见附件 `SHA256SUMS`。

GNOME 需要启用 Ubuntu AppIndicators 扩展；部分桌面只显示图标、不显示旁边文字时，点击后的菜单仍保留实时额度。桌面宠物的定位、拖动和置顶效果取决于窗口管理器，Wayland 下可能受限。完整设置方法见附件 `ubuntu-first-run.md`。

`SHA256SUMS` 包含全部五个安装文件的校验值；同时提供各平台校验文件。已有 Ubuntu 安装文件保持原样，Windows/macOS 安装包从相同标签补齐。后续版本也将从同一份源码构建三平台，通过全部检查后统一发布。

验证包括各平台前端与 Rust 测试、Windows EXE 版本核对、macOS 完整 App 和 DMG 签名校验，以及 Ubuntu 22.04 / 24.04 的原生托盘、计划任务和自启动测试。Windows/macOS 完整界面交互尚未在本次自动化流程中验证。

## English

Windows x64, Apple Silicon macOS, and Ubuntu x64 now ship together as 0.1.3, built from the same `v0.1.3` source tag. This version adds Ubuntu 22.04 / 24.04 LTS support with native AppIndicator quota labels and menus, desktop-launcher CLI discovery, npm/Node PATH handling, and Debian/AppImage packaging. Existing Windows/macOS functionality is retained.

Install the `.deb` using `sudo apt install ./QuotaMate_0.1.3_amd64.deb`, or make the AppImage executable and run it. GNOME requires AppIndicator support; some desktops show quota only in the menu. Floating pet positioning depends on the compositor, especially on Wayland. See `ubuntu-first-run.md` and `SHA256SUMS` in the assets.

Use the Windows installer or portable EXE, or install the macOS DMG. The macOS app uses verified ad-hoc signing without Apple notarization; see `macos-first-run.txt`. `SHA256SUMS` covers all five binaries. Existing Ubuntu installers are retained while the missing Windows/macOS packages are added. Future versions publish all platforms together after automated checks pass. Full Windows/macOS UI interaction is not covered by these automated build and package checks.
