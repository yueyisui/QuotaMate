# QuotaMate v0.1.2

## 更新内容

- 修复 macOS 打包后的完整 App 签名，生成并验证免费临时签名和 DMG 内的应用。
- 每 5 秒检查本机 Codex 当前账号；切换或退出登录时清空旧额度并重新连接。主页显示脱敏账号，手动刷新也会重新读取登录状态。
- 按账号实际返回的额度窗口显示内容。没有 5 小时额度时，主页、菜单栏、简洁浮窗和宠物自动使用一周或其他已返回的窗口。
- 修复额度更新后旧窗口残留的问题；未返回数据时不再误显示为额度耗尽，也不推断为无限额度。
- 增加额度适配、菜单栏显示和账号切换回归测试；本次发布已通过 25 项 Rust 测试、10 项前端测试及 macOS 构建验证。

## 下载与安装

本次提供 `QuotaMate_0.1.2_aarch64.dmg`，适用于 Apple Silicon Mac（M1 及后续芯片，包括 M5），不适用于 Intel Mac。

退出旧版应用，将 DMG 中的 `QuotaMate.app` 拖入“应用程序”并替换旧版。原有设置与自定义宠物保留。

**macOS 首次打开说明：**本版本使用免费临时签名，没有付费 Developer ID 证书或 Apple 公证，浏览器下载后仍可能被系统拦截。请先核对安装包来源和 SHA-256，再参考附件 `macos-first-run.txt`，前往“系统设置 → 隐私与安全性 → 仍要打开”。如果没有该入口，说明文件提供了仅针对 QuotaMate 的处理命令；无需关闭系统 Gatekeeper。

SHA-256：

```text
12873177fc97c902b2bcbf97307cdf979a6c2436b6729ca02a440ea92ad7651f  QuotaMate_0.1.2_aarch64.dmg
```

本次尚未提供 Windows 0.1.2 安装包，后续可从同一 `v0.1.2` 标签编译并追加到此 Release。通用代码已更新，Windows 实机验证仍需在 Windows 上完成。

**账号范围：**监控本机 Codex 当前登录账号，而非多个账号同时监控；仅在 ChatGPT 网页切换账号不会改变本机 Codex 登录。

## English

- Verified complete ad-hoc macOS app signing and the packaged DMG contents. No paid Developer ID or Apple notarization is used; first launch may still require approval. See `macos-first-run.txt`.
- Detects local Codex account switches and logout, clears old usage, and reconnects. The dashboard shows a masked account label.
- Adapts all quota displays to reported windows, including weekly-only accounts. Missing data is not treated as exhausted or unlimited quota.
- Stops restoring removed quota windows from stale snapshots. Includes account, menu-bar, and quota regression tests.

This release currently ships the Apple Silicon macOS installer only. A Windows installer can be built from the same `v0.1.2` tag and added later; Windows runtime validation is still required. Switching only the ChatGPT website account does not change local Codex credentials.
