# QuotaMate v0.1.6

修复 Ubuntu 桌面宠物的透明残影、展开收起时的位置漂移，以及快速切换显示模式后被旧操作覆盖的问题。以下行为修复均限定于 Linux；Windows 和 macOS 保留原有行为，统一升级为 0.1.6，从同一份源码构建。

- 对存在透明旧帧叠加缺陷的 WebKitGTK 使用完整透明帧，清除动画和切换形象后的重影；保留 SVG、GIF、透明度和鼠标交互。兼容绘制最多约 30 帧/秒，会增加 CPU 消耗，隐藏宠物后停止取帧；已包含上游修复的稳定版 WebKitGTK 2.52.6、2.54 及以上使用常规绘制。
- 串行处理宠物的原生缩放与移动，确认窗口实际完成变化后再继续，保持展开收起的右下角锚点、拖动后保存的位置，以及隐藏后重新打开的位置。修复最小缩放下的重复偏移和 WebKitGTK 百分比头像尺寸不稳定。
- 避开 GTK 暂停分发窗口事件的绘制阶段，防止原生窗口已改变尺寸、网页布局和输入却停留在旧尺寸。保留已经送达的移动确认，允许刚显示窗口就立即拖动；原生通知缺失时仅在变化期间进行有界确认。
- 更换形象、调整透明度等设置直接更新现有宠物，避免不必要的收起、缩放和重新定位。连续保存设置与快速切换“隐藏／顶栏／宠物”按最新操作提交，防止旧请求恢复旧设置或顶栏文字。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `QuotaMate_0.1.6_x64-setup.exe` / `QuotaMate_0.1.6_x64-portable.exe` |
| macOS Apple Silicon | `QuotaMate_0.1.6_aarch64.dmg` |
| Ubuntu 22.04 / 24.04 LTS x64 | `QuotaMate_0.1.6_amd64.deb` / `QuotaMate_0.1.6_amd64.AppImage` |

先从托盘菜单退出旧版 QuotaMate，再安装更新：

```bash
sudo apt install ./QuotaMate_0.1.6_amd64.deb
```

已有设置会保留。AppImage 下载后需添加执行权限，缺少 FUSE 时可使用 `--appimage-extract-and-run`。首次使用说明见附件 `ubuntu-first-run.md` 和 `macos-first-run.txt`，下载后请核对 `SHA256SUMS`。

## English

Fixes transparent pet trails, expansion/collapse position drift and stale display selections on Ubuntu. These behavior changes are Linux-only. Windows and macOS retain their existing behavior and share version 0.1.6, built from the same source.

Affected WebKitGTK engines draw complete transparent frames while retaining animation and input. This compatibility path runs at up to about 30 fps, uses additional CPU and stops taking frames while hidden. Stable WebKitGTK 2.52.6 and 2.54 or newer use normal drawing. Native resize/move transitions now preserve the pet's anchor, saved drag position and placement after reopening. GTK layout changes wait until event dispatch resumes, keeping native geometry, web layout and input in sync. Delivered move acknowledgements remain valid when an immediate drag follows them. Cosmetic settings update the existing pet; serialized settings saves and display selections prevent older operations from restoring stale state.

Validation so far covers the preceding `7ad10da` candidate: all four CI platforms passed, including Debian/AppImage smoke and composited-pixel checks on Ubuntu 22.04/24.04. Local checks passed 32 composited visual assertions per Linux package and 41 GNOME native-geometry assertions. Debian passed three two-CPU runs of 122 checks each and 123 missing-notification checks; AppImage passed its default 122 checks and 123 single-CPU frame-clock checks, with no transition timeouts. Single-CPU tracing found no application layout checks during GTK's paused event dispatch. Linux tests use fake Codex data without consuming quota. Missing-notification tests use a fixed anchor; normal tests separately cover real dragging. Full Windows/macOS UI interaction is outside the automated coverage.

The actual 0.1.6 Debian package and original AppImage each passed 32 visual checks on an unlocked Ubuntu 22.04 GNOME/X11 NVIDIA desktop, without forced software rendering or relaxed pixel tolerances. Checks cover six pet presets, CSS and transparent GIF animation, scale, opacity, saved placement and rapid hide/reopen; no residual pixels were detected after clearing. The new Debian package also passed 123 full single-CPU interaction checks, and AppImage passed 122 full two-CPU checks, on their first runs with no transition timeouts. None of 198 application layout checks in the Debian trace occurred during paused GTK event dispatch. The publication workflow must still rebuild the same fixed source and pass every Windows, macOS, Ubuntu 22.04 and Ubuntu 24.04 check before exposing the installers.

Quit the old app from its tray menu before updating. Install the Debian package with `sudo apt install ./QuotaMate_0.1.6_amd64.deb`, or use the AppImage, Windows installer/portable EXE or Apple Silicon DMG. Existing settings are retained. See the attached first-run instructions and verify downloads against `SHA256SUMS`.
