# QuotaMate v0.1.4

修复 Linux AppImage 在其他用户账号下启动时出现 `AppRun.wrapped: Permission denied` 的问题。Windows、macOS 和 Ubuntu 统一发布为 0.1.4，从同一份源码构建。

- 打包前校验官方 AppRun 启动器的 SHA-256，并将其权限设为 `0755`，使包内启动器可供所有用户读取和执行。
- 打包后检查 AppImage 内保存的原始 SquashFS 权限；启动器、程序或目录权限不符合要求时，构建会失败并停止导出该 AppImage。
- 增加启动器缓存和真实 SquashFS 文件的回归测试，覆盖首次构建、已有缓存、下载校验失败及 `0770` 权限问题。

## 下载与安装

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `QuotaMate_0.1.4_x64-setup.exe` / `QuotaMate_0.1.4_x64-portable.exe` |
| macOS Apple Silicon | `QuotaMate_0.1.4_aarch64.dmg` |
| Ubuntu 22.04 / 24.04 LTS x64 | `QuotaMate_0.1.4_amd64.deb` / `QuotaMate_0.1.4_amd64.AppImage` |

Ubuntu 推荐使用 `.deb`：

```bash
sudo apt install ./QuotaMate_0.1.4_amd64.deb
```

使用 AppImage 时，下载后仍需为外层文件添加执行权限：

```bash
chmod +x QuotaMate_0.1.4_amd64.AppImage
./QuotaMate_0.1.4_amd64.AppImage
```

缺少 FUSE 时可添加 `--appimage-extract-and-run`。完整 Ubuntu 设置见附件 `ubuntu-first-run.md`；macOS 首次启动说明见 `macos-first-run.txt`。`SHA256SUMS` 包含全部五个安装文件的校验值。

验证包括 Linux 打包权限回归测试、Ubuntu 22.04 / 24.04 的 Debian 和 AppImage 原生托盘与计划任务测试、Windows EXE 版本检查、macOS 完整 App 和 DMG 签名校验，以及三平台前端和 Rust 测试。Linux 冒烟测试使用模拟 Codex，不读取真实账号、不消耗额度。Windows/macOS 完整界面交互不在这些自动化检查的覆盖范围内。

## English

Fixes `AppRun.wrapped: Permission denied` when the Linux AppImage runs under a different user account. Windows x64, Apple Silicon macOS and Ubuntu x64 share version 0.1.4 and are built from the same source.

The Linux build verifies the official AppRun launcher's SHA-256 and caches it with mode `0755` before bundling. It then checks the original permissions stored in the AppImage's SquashFS filesystem. Invalid launcher, program or directory permissions stop the build before the AppImage is exported. Regression tests cover fresh and existing caches, invalid downloads and a real SquashFS image containing a `0770` launcher.

Install the `.deb` with `sudo apt install ./QuotaMate_0.1.4_amd64.deb`, or make the AppImage executable and run it. Use the Windows installer or portable EXE, or install the macOS DMG. See the attached first-run instructions and verify downloads against `SHA256SUMS`.

Automated checks cover packaging permissions, Debian/AppImage indicator and scheduler behavior on Ubuntu 22.04 and 24.04, Windows executable versions, macOS app/DMG signatures, and frontend/Rust tests on all three build platforms. Linux smoke tests use fake Codex responses without consuming account quota. Full Windows/macOS UI interaction is outside these automated checks.
