# QuotaMate v0.1.5

修复 Ubuntu 宠物模式闪退，并移除 Ubuntu 宠物周围的光晕。Windows、macOS 和 Ubuntu 继续统一使用 0.1.5 版本。

- 在创建任何 Linux 窗口和后台线程前初始化 Xlib 多线程支持，修复切换宠物模式、显示透明窗口时可能发生的 X11 原生进程崩溃。
- NVIDIA 驱动环境默认采用 WebKitGTK 的 DMA-BUF 兼容渲染路径，降低透明窗口出现残影或渲染失败的风险；保留用户显式设置的渲染环境变量。
- Linux 透明宠物窗口使用软件渲染，不再先绘制加载圆圈，避免旧画面残留。
- 仅在 Linux 桌面宠物窗口移除外发光滤镜和鼠标点击后的多余焦点轮廓，保留键盘焦点提示。
- 扩展 Ubuntu 安装包回归测试：使用模拟 Codex，检查真实 X11 初始化顺序、反复打开和隐藏宠物、点击展开、移出收起、缩放设置与位置保存，同时验证顶栏、计划任务、自启动和退出。

以上行为修复均限定于 Linux；Windows 和 macOS 沿用原有显示与窗口逻辑，从同一源码提交构建同版本安装包。

## 安装

先从托盘菜单退出旧版 QuotaMate，再安装更新：

```bash
sudo apt install ./QuotaMate_0.1.5_amd64.deb
```

安装后重新打开 QuotaMate。已有设置会保留。也提供免安装 AppImage、Windows 安装程序与免安装 EXE，以及 Apple Silicon macOS DMG；所有文件的校验值见 `SHA256SUMS`。

## English

Fixes Ubuntu desktop-pet crashes by initializing Xlib threading before GTK, display connections and worker threads. NVIDIA systems default to WebKitGTK's DMA-BUF compatibility path unless explicitly overridden. Transparent Linux pet windows use software rendering and skip the loading spinner to avoid stale frames. Linux pets no longer use surrounding glow filters or a pointer-only focus outline. Keyboard focus remains visible.

Linux package regression checks now exercise repeated pet visibility changes, real pointer interaction, expansion/collapse, saved scale, position persistence and X11 initialization order, alongside indicator, scheduler, autostart and exit checks. Tests use a fake Codex account. Windows and macOS behavior is unchanged; all three platforms use version 0.1.5 and the same source commit.

Quit the old app from its tray menu before updating, then install the Debian package with `sudo apt install ./QuotaMate_0.1.5_amd64.deb` and reopen QuotaMate. Existing settings are retained. Other packages and checksums are attached to this release.
